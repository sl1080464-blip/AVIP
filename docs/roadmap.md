# AVIP Development Roadmap

## Phase 0 — Foundation

- repository structure and conventions
- local dev environment
- Docker and CI bootstrap
- baseline documentation and security posture

## Phase 1 — Video intelligence core

- video ingestion abstraction
- frame preprocessing pipeline
- object and person detection interfaces
- tracking primitives

## Phase 2 — Event context

- zone management
- event model and event aggregation
- risk scoring pipeline
- alert publication patterns

## Phase 3 — Advanced detection

- dangerous object detection abstractions
- behavior analysis interfaces
- multi-camera orchestration

## Phase 4 — API and data integration

- FastAPI backend
- PostgreSQL schema foundation
- Redis cache and WebSocket channels

## Phase 5 — Frontend and analytics

- Next.js dashboard
- live stream and event center views
- analytics and reporting surfaces

## Phase 6 — Production readiness

- GPU optimization
- ONNX and TensorRT inference path
- deployment hardening and observability
